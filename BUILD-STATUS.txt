Wind Blower 1.2.1 source project with optional Ultra Realistic Water 1.2.2 compatibility.
No prebuilt JAR is included. The public water mod uses a custom Vulkan simulation; this project hooks its existing WaterWorld.onExplosion(Vec3, float) method by reflection when the user aims at a simulated fluid/material. This needs a real GitHub Actions build and in-game test. See BUILD-ONLINE.md.
